<h1 align="center">LMS 강의 원클릭 다운로더</h1>

<p align="center">
  학교 LMS 강의 영상을 자동으로 찾아서 <b>클릭 한 번</b>으로 받는 크롬 확장 프로그램이에요.<br>
  별도 프로그램(exe) 설치 없이 크롬만 있으면 돼요.
</p>

---

## 주요 기능

- **학교 자동 감지**: 학교 목록 없이, 열린 페이지 구조를 보고 알아서 영상을 찾아요
- **강의 제목으로 저장**: LearningX 계열 LMS는 `운영체제 3주차 - 스레드.mp4`처럼 실제 강의 제목으로 저장
- **연속 클릭 = 대기열**: 여러 강의를 연달아 누르면 차례로 받아요. 전체 다운로드 버튼도 있어요
- **빠른 다운로드**: 8MB 조각을 동시에 6개씩 받아요(2~8개 설정 가능). 연결당 속도 제한이 있는 서버에서 빨라지고, 진행률 옆에 실시간 속도(MB/s)가 보여요
  - 크롬은 서버 하나에 연결을 6개까지만 열어요. `동시 다운로드 × 파일당 연결 수`가 6을 넘으면 더 빨라지지 않으니, 보통은 **동시 1개 + 연결 6개**가 가장 빨라요
- **끊겨도 이어받기**: 연결이 끊기면 그 조각만 다시 받아요. 조각마다 크기도 검증해요
- **학교별 폴더 정리**: `다운로드/LMS/knu/`, `다운로드/LMS/ssu/`처럼 자동 분류
- **켜기/끄기 스위치**: 팝업 오른쪽 위 스위치로 영상 감지를 끌 수 있어요. 끄면 감시를 완전히 멈추고 아이콘에 `OFF`가 떠요(받던 다운로드는 계속돼요)
- **동시 다운로드 1~3개**, 영상이 하나뿐이면 아이콘만 눌러도 바로 다운로드

## 지원 범위

| 방식 | 대상 | 파일명 |
|---|---|---|
| **LearningX 모드** | 플레이어가 `https://<서버>/em/<영상ID>` 형식인 LMS<br>(자이닉스 LearningX/Commons 계열: 경북대, 경희대, 숭실대 등) | 강의 제목 |
| **영상 스니핑 모드** | 그 외 사이트에서 탭에 재생된 mp4·webm 등 | 페이지 제목 또는 영상 파일명 |
| HLS 스트리밍(`.m3u8`) | 미지원 | 아이콘에 `!` 표시와 함께 안내 |

> 경북대 LearningX 구조를 기준으로 만들었어요. 다른 학교는 플레이어 구조가 같다면 동작하지만, 아직 확인되지 않았어요. 써보시고 결과를 이슈로 남겨주세요.

## 설치

1. 이 저장소 페이지에서 **Code → Download ZIP**으로 받아서 압축 해제
2. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → `manifest.json`이 들어 있는 폴더 선택
4. 퍼즐 아이콘 → 📌 고정해두면 편해요

> - 설치할 때 **"모든 웹사이트의 데이터 읽기 및 변경"** 권한 경고가 떠요. 학교를 가리지 않고 영상을 감지하려면 이 권한이 필요해요. 수집한 정보는 어디로도 전송하지 않아요.
> - 로드한 폴더는 **옮기거나 지우면 안 돼요.** 크롬이 그 폴더에서 직접 파일을 읽어요.
> - 폴더는 **OneDrive 밖**(예: `C:\chrome-extensions\`)에 두세요. 바탕화면이나 문서 폴더는 OneDrive가 관리하는 경우가 많아요. 시간이 지나면 크롬이 파일을 못 읽어서 확장이 깨질 수 있어요.

## 사용법

1. LMS에서 강의 영상 페이지를 열어요. 아이콘에 감지된 영상 수가 표시돼요.
   - 숫자가 안 뜨면 영상을 한 번 재생하거나, 페이지를 새로고침(F5)해요
2. 아이콘 클릭 → 강의 제목 클릭 → 다운로드 시작
3. 다 받은 강의를 다시 누르면 파일이 있는 폴더가 열려요

### 저장 위치

```
<크롬 다운로드 폴더>/LMS/<학교>/<강의 제목>.mp4
예) C:\Users\<사용자>\Downloads\LMS\knu\운영체제 3주차 - 스레드.mp4
```

크롬 다운로드 폴더는 `chrome://settings/downloads`에서 확인하거나 바꿀 수 있어요.

## 동작 원리

```
[강의 페이지] ──(webRequest로 감지)──▶ background.js
                                         │  1) /em/<ID> 발견 → 같은 서버 content.php에서 제목·영상 주소
                                         │  2) 아니면 재생된 영상 요청 + 그 요청의 Referer 기록
                                         ▼
                                   대기열(queue) ──▶ offscreen.js
                                                        │  fetch + Range(8MB) 조각을 동시 6개씩 다운로드
                                                        │  (끊기면 그 조각만 재시도)
                                                        ▼
                                                  Blob ──▶ chrome.downloads로 저장
```

- 영상 서버는 대부분 `Referer` 헤더를 검사해요. 그런데 `chrome.downloads`로는 Referer를 붙일 수 없어요(`Unsafe request header`). 그래서 offscreen 페이지에서 `fetch`로 받고, Referer는 **호스트별 declarativeNetRequest 세션 규칙**으로 붙여요.
- 이 규칙은 `tabIds: [-1]` 조건이라 **확장 자신의 요청에만** 적용돼요. 평소 웹서핑에는 영향이 없어요.

| 파일 | 역할 |
|---|---|
| `background.js` | 영상 감지, 대기열, Referer 규칙, 최종 저장 |
| `offscreen.js` | 조각 병렬 다운로드, 재시도·크기 검증, Blob 생성 |
| `popup.html/js` | 강의 목록, 진행률, 설정 UI |

## 주의사항

- 다운로드 중 크롬을 끄면 그 영상은 처음부터 다시 받아야 해요.
- 학교 서버에 부담을 주지 않도록 동시 다운로드는 1~2개를 권장해요.
- 받은 강의 영상은 **개인 학습용**으로만 사용하세요. 재배포는 저작권법 및 학칙 위반이 될 수 있어요.

## 버전 기록

### v3.1.0 — 최적화
- **다운로드 속도 약 2.2배 향상**: 파일 하나를 8MB 조각으로 나눠 동시 4개 연결로 받기
  (테스트: 연결당 4MB/s 제한 서버, 60MB 영상 기준 16.1초 → 7.2초)
- 조각마다 크기를 검증해서 잘린 데이터가 섞이지 않게 함
- **평소 브라우징 부담 감소**: 모든 요청을 감시하던 것을 `<video>` 요청과 영상 확장자 URL, `/em/` 경로로만 좁힘
- 팝업: 강의 정보를 동시에 불러오고 세션 동안 캐시 → 다시 열 때 바로 표시
- 팝업: 진행 중인 다운로드가 없으면 상태 확인 주기를 늘려 불필요한 작업 줄임

### v3.0.0 — 첫 공개
- 학교 자동 감지 (LearningX 모드 + 영상 스니핑 모드)
- 별도 exe 없이 크롬 확장만으로 다운로드
- 연속 클릭 대기열, 전체 다운로드, 동시 다운로드 1~3개
- 8MB 조각 단위 다운로드, 끊김 자동 이어받기
- 호스트별 Referer 자동 규칙 (확장 요청에만 적용)
- HLS(.m3u8) 페이지 감지 시 안내
- 학교별 저장 폴더 (`LMS/<학교>/`)
